My First Day Experience at SQI

My first day at SQI was an interesting and exciting experience. I was happy to start learning about technology and programming.

I met new people and got introduced to the learning environment. At first, some of the things we were taught looked difficult, but I was encouraged to keep learning and practicing.

I was introduced to HTML and CSS, which are important technologies used in building websites. I learned about HTML tags, headings, paragraphs, links, lists, and other basic elements.

As the day went on, I became more comfortable with coding. I realized that learning how to code requires patience, practice, and consistency.

Overall, my first day at SQI was a great experience. I learned new things and became more interested in becoming a web developer.
